# Ultron — Wiki Home

**Ultron** is PromptShield reborn — minimal, deadly, text-only red highlight.

- **Extension branch:** https://github.com/sunny2196/PromptShield/tree/extension
- **Live sim:** `http://localhost:3000` (top stays **Claude**)

![Hero](https://raw.githubusercontent.com/sunny2196/PromptShield/extension/docs/images/ultron-hero.png)

## 30-second install
1. `chrome://extensions` → Developer mode ON
2. Load unpacked → select `extension/` folder
3. Set Groq `gsk_...` + Gemini `AIza...` in popup → Save
4. Open any AI: `claude.ai` / `chatgpt.com` / `gemini.google.com` / `aistudio.google.com` / `perplexity.ai` → **Ultron minimized shows just red/green dot, drag to move**
